Pedir uma busca nova

Não dá para digitar aqui e buscar na hora — a consulta roda no GitHub Actions (precisa de um token de serviço que não pode ficar no navegador). Vá em Actions → Stock Logs (busca) → Run workflow, preencha empresa (UUID), código do produto e o período, e espere ~1-2 min. O resultado aparece aqui na próxima vez que a página recarregar.
